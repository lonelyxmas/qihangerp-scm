ℹ️ 数据说明

📁 笔记文件 - 所有 .md 文件存储在笔记库目录中，支持 Markdown 格式。

📋 任务数据 - 存储在笔记库目录的 tasks.json 文件中，包含任务标题、描述、状态、优先级和截止日期。

🔔 提醒数据 - 存储在笔记库目录的 reminders.json 文件中，支持单次提醒、每日提醒、每周提醒和每月提醒。

💾 索引数据 - 存储在笔记库目录的 .index 文件夹中，包含向量索引和元数据。

🔒 本地存储 - 所有数据均存储在本地，不上传到云端，确保数据隐私安全。
