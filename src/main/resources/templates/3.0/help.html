启航 AI 协作平台 v3.0 — 功能指南与使用说明
🚀 快速开始
启航 AI 协作平台基于 Spring AI + Spring Boot，直连 LLM API，无需外部编排服务。 启动后先到 配置页 设置 LLM API Key，即可使用全部 AI 功能。
前置依赖
依赖说明必须
Java 17+运行时环境✅
LLM API KeyDeepSeek / 商汤 / 智谱等兼容 API✅
语义检索Ollama 本地 或 API（硅基流动等）🔘 可选
启动步骤
# 1. 编译
mvn package -q
# 2. 启动
java -jar target/qihang-ai-team-1.0.0.jar
# 3. 打开浏览器访问 http://localhost:6790
# 4. 在 /config 页面配置 LLM API Key
先配置 LLM API Key，否则 AI 功能不可用。支持同时配置多个模型，在对话页可随时切换。

📚 笔记库系统
一个实例可同时管理多个笔记库（如工作、学习），数据、对话、目录、任务完全隔离。 每个笔记库可配置独立的笔记存储路径，其根目录下的一级目录自动识别为笔记分区。
隔离机制
维度隔离方式
聊天历史sessions.kb_id + 向量召回限定 kb_id
笔记目录笔记库根目录自动扫描，支持排序/隐藏
AI 记忆{notesDir}/AI/记忆/ 隔离
任务/提醒{notesDir}/AI/任务/ + AI/提醒/ 隔离
文件操作基于当前笔记库路径
笔记功能
  • 目录浏览 — 按笔记分区查看文件目录结构
  • Markdown 预览 — 渲染为 HTML 在线查看
  • 文件操作 — 新建、编辑、删除 .md 文件
  • AI 分析 — 流式分析目录内容并生成洞察报告
💬 AI 对话
连续对话模式，SSE 流式输出。AI 根据当前笔记库的历史记录和语义检索结果进行回答，可自主调用工具操作笔记库。
工作模式
  • 笔记库对话（默认）— 注入历史上下文 + 语义检索，适合基于笔记库的问答
  • 创作式对话 — 无历史上下文，适合独立创作或开放讨论
AI 工具（自动编排）
工具功能触发场景
readFile读取笔记库文件内容AI 需要了解数据格式或历史内容
writeFile写入文件（先读后写，防覆盖）创建/更新记录、文档
listDir列出目录内容AI 需要探索笔记库结构
searchFiles按文件名关键词搜索查找特定文件
语义检索
  • Ollama 本地 — 不填 API Key，使用本地 Ollama（推荐 bge-m3）
  • API 模式 — 填入 API Key，支持硅基流动等 OpenAI 兼容服务
AI 回复后自动生成向量并跨会话检索相似轮次（余弦相似度阈值 0.5），最多从 8 轮最相关的历史中提取上下文。
🔧 工具集
🎨 AI 绘图
通过 AI 生成图片。在工具页进入 AI 绘图，输入文字描述，选择模型和尺寸，点击生成即可。 需要先在配置页添加类型为「生成图片」的模型。
🖼️ 通用识图
基于多模态 Vision API 的图片分析功能。支持上传本地图片或从笔记库浏览选择图片进行识别。 分析结果可保存到笔记库。需要配置多模态模型。
📊 数据分析
打开笔记库中的 JSON 数据文件，AI 自动分析数据结构、关键指标、趋势和异常点， 生成结构化的洞察报告。
🗂️ 数据中心
集中管理结构化数据集，支持多数据集、Schema 定义、批量导入导出。
  • 创建数据集（定义 Schema：字段名、类型、描述、必填、默认值）
  • Excel 导入 — 自动检测列头、模糊匹配字段映射，支持 AI 智能归一化
  • JSON 导入 — 直接粘贴或上传 JSON 数据
  • 记录浏览、搜索、删除，自动 MD5 去重
  • 可将数据集导出到笔记库目录
📋 任务与提醒
任务看板和定时提醒统一管理，数据按笔记库隔离。
任务看板
  • 字段：标题、描述、状态（待办/完成）、优先级（高/中/低）、截止日期
  • 按笔记库隔离，名称可自定义
  • 数据存储在 {notesDir}/AI/任务/data.json
定时提醒
  • 重复类型：一次性、每日、每周、每月、每年
  • 通过飞书 Webhook 推送提醒消息
✈️ 飞书集成
支持 Webhook 消息推送和 WebSocket 长连接双向通信。
Webhook 推送
  • 日报推送、定时提醒推送
  • 在配置页填写 Webhook URL 即可
WebSocket 长连接
  • 通过飞书 OpenAPI SDK 建立长连接，实时接收群内消息
  • AI 处理消息后自动回复，支持单聊和群聊
  • 去重机制防止重复处理
配置步骤
  1. 在飞书开放平台创建应用，获取 App ID / App Secret
  2. 在配置页填写凭据并选择目标群
  3. 开启"消息接收"开关
⚙️ 系统配置
所有配置通过 配置页 管理，无需手动编辑文件。
配置项说明

语义向量模型配置用于语义检索的向量模型（Ollama 本地 或 API）
飞书 Webhook消息推送 URL
飞书消息接收App ID / Secret / Chat ID，WebSocket 长连接接收消息
字段标签英文 key → 中文标签映射

🏗️ 技术架构
组件技术
框架Spring Boot + Spring AI + Java 17
AI 引擎ChatClient 直连 LLM（OpenAI 兼容协议）
工具编排@Tool 注解 + ToolCallingAdvisor（自动路由）
语义检索Ollama（bge-m3 等）/ 兼容 API
会话存储MySQL（MyBatis-Plus）— ai_sessions / ai_messages
笔记库存储JSON / Markdown 文件（本地文件系统）
前端Thymeleaf 模板，紧凑 64px 侧边栏布局
飞书集成OpenAPI SDK（WebSocket）+ HttpURLConnection（Webhook）
❓ 常见问题
问题原因解决
AI 回复"API Key 未配置"未在 /config 填写 API Key配置页填写 LLM API Key
AI 回复为空LLM 超时或返回空检查网络，超时设为 600s
"未配置笔记库"未添加笔记库或未配置路径在笔记库管理页添加笔记库
语义检索不可用Ollama 未启动或向量模型未配置启动 Ollama 或配置 API 模式的向量模型
飞书消息收不到WebSocket 未连接或 Webhook 未配置在配置页检查飞书凭据
对话记录丢失切换了笔记库每个笔记库的对话独立，切换回对应笔记库即可
AI 绘图不可用未配置图片生成模型在配置页添加类型为「生成图片」的模型
通用识图不可用未配置多模态模型在配置页添加多模态模型
